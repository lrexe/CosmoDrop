# Vloody

Telegram Mini App для честных PvP-розыгрышей NFT-подарков.
Flask + SQLite (или PostgreSQL) на бэкенде, одностраничный интерфейс без сборщика (HTML/CSS/JS)
в голубой гамме: тёмная тема «Глубина» и светлая «Лёд», раскладки для телефона и десктопа.

## Модель

Организатор вносит подарок и открывает раунд, игроки делают ставки во внутренней валюте VLD,
победитель забирает подарок, организатор — 90% банка, платформа — 10% комиссии.

**Платформа никогда не платит из своего кармана**: любая выплата — это перераспределение
ставок самих игроков. Поэтому подкручивать результат платформе незачем, и она этого не делает.

## Режимы

| Режим | Как работает |
|-------|--------------|
| 🎡 **Колесо** | Шанс участника равен его доле в банке. Розыгрыш по таймеру. |
| 🔒 **Кибер-сейф** | Попытка угадать секретное число за фиксированную ставку. Каждое число занимается один раз, угадавший забирает подарок сразу. |
| 🕶 **Слепой аукцион** | Ставки скрыты, накапливаются и не возвращаются. Побеждает наибольшая сумма; при равенстве — кто достиг её раньше. |

## Защита игроков

- **Эскроу подарка.** Раунд создаётся только из подарка, который бот-хранитель уже получил в Telegram.
  Разыграть несуществующий приз нельзя; победителю подарок переходит автоматически.
- **Организатор не участвует** в своём раунде и не может отменить его после первой ставки.
- **Секрет сейфа выбирает сервер**, а не организатор — слить число «своему» игроку нельзя.
- **Проверяемость.** При создании публикуется `seed_hash`, после завершения раскрывается `seed`:
  - колесо: `seed_hash = sha256(seed)`, билет = `HMAC-SHA256(seed, "id:банк:ставок") mod банк`;
  - сейф: `seed_hash = sha256("число:seed")`.
- **Личность по подписи Telegram** (`initData`, HMAC на `BOT_TOKEN`); `telegram_id` из запроса игнорируется.
- Имена очищаются от HTML, есть лимит частоты запросов.

## Экономика

| Операция | Комиссия платформы |
|----------|--------------------|
| Раунд | 10% банка |
| Покупка VLD за Telegram Stars | 5% (100 ⭐ → 95 VLD) |
| Покупка VLD за TON | нет, по курсу `VLD_PER_TON` |
| Перевод другу (от 150 VLD) | 10% |
| Вывод в TON (от 100 VLD) | 10%, заявку подтверждает администратор |
| Вывод в Telegram Stars (от 100 VLD) | 20%, заявку подтверждает администратор |
| Рефералы | рефереру 1% ставок друга — **из комиссии платформы** |

Все движения записываются в журнал `ledger`; доход платформы — строки с `user_id = NULL`.

## 💎 VLD и TON

**VLD** — единая внутренняя валюта: в ней ставки, банки, переводы и комиссии.

- **Пополнение звёздами** — счёт Telegram Stars, зачисляется `stars × 0.95`.
- **Пополнение TON** — сервер выдаёт адрес кошелька платформы и уникальный комментарий.
  Игрок переводит TON из любого кошелька (через TON Connect или по ссылке `ton://transfer/...`),
  сервер находит перевод в блокчейне через toncenter и зачисляет VLD по фактически пришедшей сумме.
  Каждая транзакция зачисляется один раз; перевод без комментария или меньше минимума не зачисляется.
- **Вывод** — заявка, которую администратор выплачивает вручную со своего кошелька.
  **Приватного ключа на сервере нет**, поэтому взлом сервера не даёт доступа к деньгам.
  Для TON сумма к выплате фиксируется по курсу на момент заявки.

**Настройка TON:** задай `TON_WALLET_ADDRESS` (кошелёк платформы), желательно `TON_API_KEY`
(ключ toncenter — без него жёсткий лимит запросов) и `VLD_PER_TON`. Для тестовой сети:
`TON_API_BASE=https://testnet.toncenter.com/api/v2`. Чтобы депозиты зачислялись, даже если игрок
закрыл приложение, дёргай по cron раз в минуту `POST /api/admin/ton/scan` с заголовком `X-Admin-Secret`.

### ⚠️ Курс VLD

Курс TON фиксированный (`VLD_PER_TON`, по умолчанию 100, т.е. 1 VLD = 0.01 TON), курс звёзд — тоже.
Если они разойдутся с рынком, появится **арбитраж**: купить VLD дешёвым способом и вывести дорогим.
Это единственное место, где платформа может начать платить из своего кармана. Поэтому:

- подбирай `VLD_PER_TON` так, чтобы 1 VLD через TON стоил не дешевле, чем через Stars,
  и пересматривай при заметном движении цены TON;
- каждую заявку на вывод подтверждает человек — смотри, откуда у игрока VLD (`/api/transactions`, журнал `ledger`).

## 🛠 Админ-панель

Страница **`/admin`** (удобнее с компьютера). Вход по `ADMIN_SECRET`; секрет хранится только
во вкладке браузера. После 10 неверных попыток с одного IP вход блокируется на 10 минут.
В демо-режиме без заданного секрета пускает по слову `demo` — только для локальных проб.

- **Обзор** — доход за день, неделю и всё время, обязательства перед игроками, что требует внимания.
- **Выводы** — заявки: «Выплачено» (после реальной отправки денег) или «Отклонить» (сумма возвращается игроку).
  Для TON есть кнопка, открывающая кошелёк с уже заполненными адресом и суммой.
- **Раунды** — все раунды; «Отменить с возвратом» возвращает ставки игрокам и подарок организатору.
- **Игроки** — поиск по ID или @username, история операций, блокировка.
- **Подарки** — что ждёт выдачи ботом-хранителем, что в инвентарях и раундах.
- **Доход** — журнал комиссий и депозиты TON.

Начислить игроку VLD вручную нельзя намеренно: это был бы единственный способ создать деньги из воздуха.
Держи `/admin` за HTTPS и задай длинный случайный `ADMIN_SECRET`.

## ▶️ Запуск локально

```bash
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt   # Linux/macOS: .venv/bin/python
.venv/Scripts/python seed.py     # демо-игроки, подарки и раунды
```

мгновенное пополнение и кнопка «получить демо-подарок».

## 🎨 Темы и раскладки

**Темы.** Тёмная (основная) и светлая: атрибут `data-theme="dark|light"` на `<html>`. Все цвета — токены
в `static/css/vl-tokens.css`; без атрибута действуют значения тёмной темы. Тему выставляет `static/js/vl-theme.js`
в `<head>`, до первой отрисовки. Порядок выбора:

1. сохранённый выбор игрока — `localStorage["vl_theme"]` (если хранилище недоступно, выбор живёт в памяти до перезагрузки);
2. тема Telegram (`Telegram.WebApp.colorScheme`), если приложение открыто в Telegram;
3. системная тема (`prefers-color-scheme`);
4. иначе тёмная.

Переключатели — в верхней строке (телефон), в боковой панели (десктоп) и в профиле («Оформление»).
Скрипт синхронизирует `<meta name="theme-color">` и цвет шапки Telegram с `--bg`.
Админка (`/admin`) использует те же токены и свой переключатель.

**Раскладки** (только CSS, порог в `static/css/vl-shell.css`):

- **телефон, до 860px** — колонка, сверху строка с балансом, снизу навигация из 5 пунктов с центральной кнопкой «Создать»,
  модальные окна — шторки снизу;
- **десктоп, от 861px** — боковая панель 248px (разделы, баланс, тема), контент до 1180px по центру,
  раунды сеткой в несколько колонок, экраны раунда и профиля в две колонки, модальные окна — диалоги по центру.

Каркас (`templates/vloody.html`): `#app > #shell` → `aside#sidebar` (десктоп), `main#content` (демо-полоса,
`header#topbar`, `#screens` — единственная прокручиваемая область), `nav#tabbar` (телефон). Экраны — `div.scr`,
виден тот, у которого `.on`; смену анимирует `static/js/vl-fx.js` (до 220 мс). При `prefers-reduced-motion`
движение и 3D отключаются, содержимое остаётся.

## 🖼 Картинки подарков

Показываются только настоящие картинки; если получить их не удалось — запасная плитка (градиент из названия и монограмма).

| Что | Источник | Маршрут у нас |
|-----|----------|---------------|
| NFT-подарок | публичное хранилище Fragment: `<GIFT_CDN_BASE>/<slug>.medium.jpg`, `.webp`, `.lottie.json` (анимация) | `/gift-art/<slug>.jpg` · `.webp` · `.json` |
| Обычный подарок за Stars | официальный Bot API `getAvailableGifts` (превью стикера в webp; нужен `BOT_TOKEN` или `RELAY_BOT_TOKEN`) | `/gift-art/regular/<id>.webp`; список — `GET /api/gifts/catalog` |

- `slug` — уникальное имя NFT-подарка в нижнем регистре (например `plushpepe-1337`), хранится в `GiftItem.slug`;
  бот-хранитель передаёт его при приёме подарка.
- Картинки скачивает **сервер** (`bot/giftart.py`): проверяет формат slug, тип и размер ответа, редиректы не выполняет,
  кладёт файл в дисковый кэш **`instance/gift_cache`** и отдаёт со своего адреса. Клиенты к Fragment и Telegram не ходят.
- Это не открытый прокси: `/gift-art/<slug>` отдаёт только slug из нашей таблицы подарков, `/gift-art/regular/<id>` —
  только id из каталога `getAvailableGifts`. Промах CDN запоминается на 10 минут, каталог — на 6 часов.
- `GIFT_CDN_BASE` — адрес хранилища NFT-картинок (по умолчанию `https://nft.fragment.com/gift`).

> ⚠️ **Риск.** `nft.fragment.com` — не официальный API Telegram, а публичное хранилище Fragment: оно может поменять адреса
> или ограничить запросы. Поэтому кэш обязателен, а при сбое интерфейс показывает запасную плитку. Если адрес поменяется,
> задай новый в `GIFT_CDN_BASE`. Изображения принадлежат Telegram и авторам коллекций; показываем их только для реальных подарков на платформе.

## 📦 Бот-хранитель подарков (`bot/relay.py`)

Боты в Telegram не умеют получать подарки сами. Поэтому подарки принимает обычный аккаунт
с **Telegram Business** (аккаунт-хранитель), а бот подключён к нему как бизнес-бот и действует от его имени.

**Настройка**

1. Заведи отдельный аккаунт-хранитель (например `@VloodyRelay`) с Telegram Premium.
2. Создай в @BotFather **отдельного** бота и включи ему Business Mode (Bot Settings → Business Mode).
   Основной бот не подойдёт: он получает оплату через вебхук и не может одновременно опрашиваться.
3. На аккаунте-хранителе: Настройки → Telegram для бизнеса → Чат-боты → укажи этого бота
   и выдай права: просмотр подарков и звёзд, передача подарков, перевод звёзд.
4. Держи на аккаунте-хранителе запас звёзд: Telegram берёт плату за передачу подарка.
   Эти звёзды заранее списываются с игрока, который выводит подарок, — платформа не доплачивает.
5. Запусти:

```bash
RELAY_BOT_TOKEN=... RELAY_SECRET=... VLOODY_URL=https://твой-сервер python -m bot.relay
```

**Что он делает**

- Раз в `RELAY_SYNC_SEC` секунд сверяет подарки на аккаунте и зачисляет новые NFT-подарки их отправителям.
- Не трогает подарки, полученные до первого запуска, обычные (не NFT) и от скрытых отправителей.
- Передаёт подарки по заявкам на вывод; если у Telegram пауза на передачу — ждёт.
- После 5 неудачных попыток возвращает подарок в инвентарь и плату за передачу — игроку.
- Состояние хранит в `instance/relay_state.json`; **не удаляй этот файл** — в нём момент первого запуска
  и список уже зачисленных подарков.

Переменные: `RELAY_BOT_TOKEN`, `RELAY_SECRET`, `VLOODY_URL` (по умолчанию `http://127.0.0.1:5000`),
`RELAY_STATE`, `RELAY_SYNC_SEC` (15).

## ⚙️ Конфигурация (env)

- `BOT_TOKEN` — токен бота. **Если задан — боевой режим**: API принимает только подписанный `initData`,
  пополнение идёт через счёт Telegram Stars, демо-подарки выключены.
- `DEMO_MODE=1` — оставить демо-режим даже при заданном `BOT_TOKEN`.
- `SECRET_KEY` — секрет Flask (в боевом режиме обязателен).
- `TON_WALLET_ADDRESS`, `TON_API_KEY`, `TON_API_BASE`, `VLD_PER_TON`, `TON_MIN_DEPOSIT` — см. «VLD и TON».
- `TELEGRAM_WEBHOOK_SECRET` — секрет вебхука оплаты (`secret_token` в `setWebhook`).
- `RELAY_SECRET` — секрет бота-хранителя подарков (заголовок `X-Relay-Secret`).
- `ADMIN_SECRET` — секрет админ-API (заголовок `X-Admin-Secret`).
- `BOT_USERNAME`, `RELAY_USERNAME` — юзернеймы основного бота и бота-хранителя.
- `LEGACY_GAMES=1` — вернуть старые игры CosmoDrop (кейсы, ракета, мины, кости, апгрейд, колесо).
  По умолчанию выключены: в них платформа платила выигрыши сама.
- `DB_HOST`, `DB_USER`, `DB_PASSWORD`, `DB_NAME` — PostgreSQL вместо SQLite.
- `GIFT_CDN_BASE` — хранилище картинок NFT-подарков, см. «Картинки подарков».
- `INIT_DATA_MAX_AGE`, `RATE_LIMIT`, `HOST`, `PORT`, `DEMO_TELEGRAM_ID` — прочее.

| Метод | Эндпоинт | Назначение |
|------|----------|-----------|
| GET · POST | `/api/pools` | список раундов · создать раунд из подарка |

| GET · POST | `/api/inventory/gifts` · `/api/inventory/gifts/<id>/withdraw` | подарки · запрос выдачи |
| POST | `/api/wallet/topup` | покупка VLD за Stars (демо — сразу, бой — счёт) |
| POST | `/api/wallet/ton/intent` · `/api/wallet/ton/check` | адрес и комментарий для перевода TON · проверка зачисления |
| POST | `/api/transfer` · `/api/payout` | перевод другу · заявка на вывод |

| GET · POST | `/api/admin/stats` · `/payouts` · `/pools` · `/pools/<id>/refund` · `/users` · `/gifts` · `/revenue` · `/ton/scan` | админ-панель |
| POST | `/api/telegram_payment` | вебхук оплаты Telegram Stars |
